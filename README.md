## ⭐ Featured project: [Opsboard](https://github.com/Javohir-dev/Opsboard)

A local dashboard for developers who work with Claude Code: sessions and agents, Claude usage limits, GitLab/GitHub merge requests, Jira tasks, Docker and Postgres, all in one browser tab.

- Pure Python 3, standard library only (no `pip install`)
- GitLab, GitHub and Jira integrations; one-click background fix runs with your own Claude skill
- Runs locally on `127.0.0.1`; tokens go only to your own code host and Jira
- UI in English, Uzbek and Russian; MIT licensed, with CI and tests
